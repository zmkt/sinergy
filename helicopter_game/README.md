# Пожарный вертолёт — консольная игра на Python

Лес растёт и периодически загорается. Игрок управляет вертолётом: набирает воду
над рекой, тушит горящие деревья, зарабатывает очки, покупает улучшения и жизни.

## Запуск

```bash
cd helicopter_game
python3 main.py
```

В меню выбирается новая игра или продолжение сохранённой, затем размеры поля
и режим отрисовки (эмодзи или простые символы — если терминал криво рисует эмодзи,
отвечайте `н`).

## Управление

| Клавиша | Действие |
|---|---|
| `w` `a` `s` `d` | полёт вверх / влево / вниз / вправо |
| `e` | потушить пожар под вертолётом |
| `b` | купить резервуар для воды (в клетке магазина) |
| `h` | купить жизнь (в клетке госпиталя) |
| пробел | пропустить ход |
| `k` | сохранить игру |
| `l` | загрузить игру |
| `q` | выход |

Клавиши работают и в русской раскладке (`ц` `ф` `ы` `в` и т. д.).

## Правила

- **Тик.** Каждое действие игрока — один тик. За тик лес растёт, движется погода,
  горящие деревья догорают.
- **Вода.** Пролёт над рекой наполняет все резервуары. Один резервуар = один
  потушенный пожар. Дождь тоже наполняет резервуары.
- **Огонь.** Дерево горит `FIRE_TICKS` тиков. Не потушили — оно сгорает в
  пепелище, а огонь перекидывается на соседние деревья, по ветру — гарантированно.
- **Очки.** +10 за потушенное дерево, −15 за сгоревшее.
- **Жизни.** Старт с 3, максимум 5. Жизнь теряется, если влететь в огонь без воды,
  остаться в горящей клетке или попасть под молнию.
- **Погода.** Ветер меняет направление и разгоняет огонь. Дождевые облака тушат
  пожары, грозовые бьют молниями и поджигают лес.
- **Покупки.** Магазин: +1 резервуар за 50 очков. Госпиталь: +1 жизнь за 40 очков.
- **Конец игры.** Жизни кончились — игра окончена.

## Структура проекта

| Файл | Назначение |
|---|---|
| `main.py` | меню, выбор размеров поля, запуск |
| `game.py` | состояние игры, тики, отрисовка, обработка клавиш |
| `field.py` | поле: границы, реки, деревья, пожары, случайные клетки |
| `helicopter.py` | вертолёт: движение, вода, тушение, жизни, очки |
| `weather.py` | ветер, облака, дождь, грозы и молнии |
| `shop.py` | магазин улучшений и госпиталь |
| `storage.py` | сохранение и загрузка игры в JSON |
| `keyboard.py` | чтение клавиши без Enter |
| `config.py` | картинки клеток, баланс, цены, раскладка клавиш |
| `saves/` | файлы сохранений |

## Настройка баланса

Все коэффициенты собраны в `config.py`: скорость роста леса, шанс самовозгорания,
скорость распространения огня, частота гроз, цены и очки. Меняются без правки
остального кода.
